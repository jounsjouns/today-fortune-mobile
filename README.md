# 오늘의 운세

모바일 우선으로 만든 오늘의 운세 PWA 웹앱입니다.

## 주요 기능

- 오늘의 한 줄 운세
- 연애운, 금전운, 직장운, 행운지수
- 12띠별 운세 카드
- 선택한 띠의 상세 운세
- 행운의 색상, 숫자, 방향, 아이템
- 이메일 구독 CTA
- 프리미엄 운세 CTA
- 광고 영역 placeholder
- PWA 기본 설정

## 실행 방법

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 배포

Vercel에서 이 저장소를 연결하면 Next.js 프로젝트로 자동 인식됩니다.

- Build Command: `pnpm build`
- Install Command: `pnpm install`
- Output Directory: Next.js 기본값 사용
